# Chai Nasta Corner - Online Snacks & Tea Store

A modern cafe and snacks ordering website featuring categorized menus, an interactive shopping cart, and a demo checkout flow.

## Live Demo
👉 [View Live Website]( https://shanidev919.github.io/Chai-Nasta/)

## Features
- Categorized menu (Food, Tea & Coffee, Biscuits, Namkeen)
- Add-to-cart functionality with live subtotal calculation
- Demo checkout system with order confirmation
